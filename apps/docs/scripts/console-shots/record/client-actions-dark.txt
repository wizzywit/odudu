Audiences
Add audience
The resource servers tokens issued to this client are meant for, which a token names as its audience. A request may narrow them with a resource, never widen them. 0 of 200 audiences.
Token exchange
Allow impersonation in token exchange
Off
On, this client may exchange a token for one that stands for the subject with no actor named. Off, an exchange it makes names the client as the actor. It has no effect unless the client holds the token exchange grant.
Allow a public client to use token exchange
Off
A public client holds no secret, so it is refused the token exchange grant unless this is on. It has no effect on a confidential client, or unless the client holds the token exchange grant.
Accept an actor token issued to another client
Off
An actor token issued to another client is refused unless this is on. It has no effect unless the client holds the token exchange grant.
Application actions
The account changes this client may ask Odudu to run for a person who is signed in, through a parameter of its authorization request. A client may start none until one is chosen here.
Actions an application may start
Verify the email address
Asks the person to prove the address on file with a link sent to it.
Choose a new password
Asks for the current password, then a new one.
Set up an authenticator app
Enrols an authenticator app as a second factor.
Register a passkey
Registers a passkey on the device in use.
Generate recovery codes
Shows a fresh set of recovery codes once, replacing any held.
Complete the profile
Asks the person to fill in every profile field that is still empty.
Sign-in flow
The steps a person goes through to sign in to this application. Tenant default follows whichever flow the tenant marks as its default; choosing a flow by name keeps this client on it even when the default changes. A sign-in already under way stays on the flow it started with.
