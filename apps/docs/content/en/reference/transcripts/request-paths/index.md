# Request paths

These are the full transcripts behind the [guides](../../../guides/index.md): every request a client or a browser makes to the protocol endpoints, and the exact answer that came back. Reach for them when you want every header and every byte rather than the short version.

Each block is a command that was run and the output it printed. Values that change on every run, such as codes, tokens and ids, are shortened where they appear, and the page says so.

How they were captured is in [How the transcripts are captured and checked](../../../contributing/transcripts.md).
